angular.json - Angular workspace configuration file.

tsconfig.json - Base TypeScript compiler configuration.

tsconfig.app.json - TypeScript configuration for the Angular application.

package.json - Lists project dependencies and npm scripts.

src/main.ts - Entry point that bootstraps the Angular application.

src/app/app.config.ts - Configures application providers and routing.

src/app/app.ts - Root Angular component of the application.

src/index.html - Main HTML page where the Angular application is loaded.
