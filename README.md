# 🚀 Digital Nurture 5.0 – Java Full Stack Engineer (Java FSE)

This repository contains my solutions, projects, and hands-on exercises completed as part of the **Cognizant Digital Nurture 5.0 – Java Full Stack Engineer (Java FSE) Deep Skilling Program**.

The program is designed to build strong software engineering fundamentals, backend development skills using Spring Boot, frontend development with React, testing practices, DevOps concepts, cloud fundamentals, and Generative AI awareness through practical hands-on exercises.
